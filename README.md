# Hide Haven — Next.js + Tailwind Minimal Scaffold

Files added:

- `modules/homepage/homepage.jsx` — Converted homepage from Figma
- `pages/index.js` — Renders the homepage
- `styles/globals.css`, `tailwind.config.js`, `postcss.config.js` — Tailwind setup

Quick start:

1. Install deps:

```bash
cd c:\Users\Jubayer\Desktop\Dhrubo_aap
npm install
```

2. Run dev server:

```bash
npm run dev
```

Notes:
- This scaffold uses the Figma-exported asset URLs (temporary). Consider downloading assets into `public/` and replacing URLs.
- If you already have an existing Next.js app, move `modules/homepage/homepage.jsx` into your components and import accordingly.
